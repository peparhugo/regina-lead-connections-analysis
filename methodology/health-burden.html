Model Overview

The health burden model estimates harm from childhood lead exposure using:

  1. Exposure model: Child-exposure-years based on time living with lead service connection
  2. Harm model: QALY loss per exposure-year from epidemiological literature
  3. Cost model: Healthcare costs derived from CIHI pediatric cost proxies

QALY Calculation

QALY_Loss_CT = Exposure_Years_CT × QALY_per_Exposure_Year

Where:

  • Exposure_Years_CT: Impacted children × average years of exposure (assumed 5 years for realized, based on program timeline)
  • QALY_per_Exposure_Year: 0.015 - 0.025 range from literature (we use 0.02 base case)

Healthcare Cost Calculation

Cost_CT = QALY_Loss_CT × Cost_per_QALY

We use CIHI (Canadian Institute for Health Information) pediatric cost proxies:

PostGIS Implementation

-- Materialized view: ct_child_qaly_20260324
SELECT
  ct_uid_code,
  ct_name,
  impacted_children_0_14_est,
  realized_child_exposure_years_base * 0.02 as realized_qaly_base,
  avoided_child_exposure_years_base * 0.02 as avoided_qaly_base,
  projected_child_exposure_years_base * 0.02 as projected_qaly_base
FROM regina.ct_child_harm_exposure_20260324;

Assumptions & Limitations

  1. Population-level model: Individual outcomes vary; this is an aggregate policy analysis tool
  2. Linear dose-response: Assumes harm is proportional to exposure duration (may underestimate non-linear effects)
  3. 2016 demographics: Child counts from 2016 Census; actual 2026 population may differ
  4. Filter adjustment: Assumes 25% filter program uptake reduces exposure proportionally
  5. Cost stability: Healthcare costs assumed constant; actual costs may vary with inflation and care patterns

Reproduce This Analysis

# Connect to PostGIS
docker exec -it regina-postgis-20260324 psql -U regina -d regina

# Query QALY totals
SELECT
  round(sum(realized_qaly_base)::numeric, 1) as realized,
  round(sum(avoided_qaly_base)::numeric, 1) as avoided,
  round(sum(projected_qaly_base)::numeric, 1) as projected
FROM regina.ct_child_qaly_20260324;

# Query healthcare costs
SELECT
  round(sum(realized_healthcare_cost_base)::numeric / 1000000, 2) as cost_millions
FROM regina.ct_child_healthcare_cost_20260324;

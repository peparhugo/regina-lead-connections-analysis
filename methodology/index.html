Methodology & Data Sources

Every claim on this site is backed by verifiable data sources. This page documents our methodology, assumptions, and provides instructions to reproduce any calculation.

Principles

  • Transparency: All data sources are public and cited with access dates
  • Reproducibility: Any calculation can be reproduced with the provided scripts
  • Conservative estimates: Where uncertainty exists, we use the more conservative assumption
  • Versioned data: Snapshots preserve the state at time of analysis

Reproduce Our Analysis

All analysis scripts are available in the repository:

git clone https://github.com/peparhugo/regina-lead-connections-analysis
cd regina-lead-connections-analysis/scripts
python3 build_replacement_diff.py  # Derive replacements
python3 build_ct_kepler_dataset.py # Build CT synthesis

PostGIS materialized view definitions are exported to data/derived/matview_definitions_20260401.sql

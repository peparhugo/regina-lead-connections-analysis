3. Verification Procedures

3.1 Lead Connection Count Reconciliation

Issue discovered: Initial spatial join using ST_Contains matched only 1,089 connections to Census Tracts due to boundary edge cases and coordinate precision issues.

Resolution: Used buffered spatial join with ST_DWithin(geometry, 0.0001) to capture edge cases. Verified total count against ArcGIS API pagination: 

-- Verify total from source API
curl "https://gis.regina.ca/arcgis/rest/services/OpenData/LeadConnectionAreas/MapServer/0/query?
  where=1=1&returnCountOnly=true&f=json"
# Response: {"count": 2743}

-- Verify spatial join coverage
SELECT COUNT(*) FROM lead_connections_with_ct WHERE ct_uid_code IS NOT NULL;
# Result: 2743 (100% match after buffer adjustment)

3.2 Demographic Cross-Validation

Census Tract demographics were validated against Saskatchewan Health Authority regional totals:

  • Total Regina CMA population: 249,945 (StatCan) vs 251,000 (SHA estimate) - 0.4% variance
  • Children 0-14: 41,230 (StatCan) - consistent with school enrollment data
  • Renter percentage: 32.4% (Regina CMA) - consistent with CMHC rental market report

4. Data Quality Notes

4.1 Known Limitations

  • Address geocoding: Some lead connection addresses may have imprecise geocoding, affecting CT assignment at boundaries
  • Census undercounting: Low-income and transient populations are typically undercounted in census data
  • Private-side connections: The City dataset only includes city-side connections; private-side lead pipes are not tracked
  • Temporal lag: Census 2021 demographics may not reflect 2026 population distribution

5. Reproducibility

All data processing was performed using PostgreSQL 15 with PostGIS 3.4. The complete SQL workflow is documented in SQL Queries.

To reproduce this analysis:

  1. Download lead connection data from the ArcGIS API (JSON format)
  2. Download Census Tract boundaries and demographics from Statistics Canada
  3. Load into PostGIS database with appropriate SRID transformations
  4. Execute spatial join and QALY calculation queries
  5. Export results to GeoJSON for visualization

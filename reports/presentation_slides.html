The Idea Behind It

World Models
→ Belief Models

In 2018, Ha & Schmidhuber showed agents can learn inside their own dreams — building compressed world models, then training on predictions.

World Models (Ha & Schmidhuber 2018)

Agent learns inside its own dream

Vobserve
Mmodel
Cdecide

Compress observations → build a predictive model → train inside the model. Add noise to prevent exploiting imperfections.

Dream Lab / JVB (our adaptation)

System learns by attacking its own beliefs

📥observe
🐒believe
⚔️attack
✅know

Workers generate beliefs → counterargument agent stress-tests them → JVB review adjudicates what survives. The "noise" is adversarial scrutiny.

The parallel: World Models add noise to prevent dream exploitation. We add a counterargument monkey to prevent belief exploitation.

Orchestration

OpenClaw spawns agents as subprocesses. Workers run in batches of 3. Profile-driven activation: 5 required + 3 random per cycle (genetic algorithm pattern).

JVB Pipeline

3 n8n workflows: intake → build-claim-batch → review-and-revise. Per-condition gate evaluation with fail-closed normalization.

Data

PostGIS: 22 tables + 15 materialized views. 87K address points, 1.1K replacement events, child harm / QALY / cost models per census tract.

Hosting

Single VPS. Docker containers for PostGIS, Neo4j, n8n, VictoriaMetrics. GitHub Pages for public site. Everything on one box.

## 4. Lane classes
### Core validation / canonical package lane
Definition:
- the already-established evidence/package/control layer supporting the current `pass_with_repairs` posture

### Enrichment lane
Definition:
- additive analysis or data lanes that improve scope, confidence, granularity, or accountability but do not retroactively prove core validation was absent

### Support lane
Definition:
- useful supporting artifacts that can guide understanding, navigation, chronology, or secondary argumentation, but are not top-line claim authority

### Appendix-only lane
Definition:
- valuable but too technical, inferential, or fragile for headline/public core use without stronger validation

### Blocked lane
Definition:
- candidate claims, framings, or analytical interpretations that are not yet safe to promote
